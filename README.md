- **Live Demo**: [https://durnazeynalli.github.io/journey/](https://durnazeynalli.github.io/journey/)

- **HTML5**

```text
├── images/

├── index.html          # Main HTML entry point

```

## Getting Started

Since this is a static website with no external dependencies or build tools, you can run it locally in any web browser.

1. Clone the repository:
   ```bash
   git clone https://github.com/durnazeynalli/journey.git
   ```
2. Open `index.html` directly in your web browser, or serve it using any local static file server (e.g., Python or Live Server):
   ```bash
   cd journey
   python3 -m http.server 8000
   ```
3. Navigate to `http://localhost:8000` in your browser.
